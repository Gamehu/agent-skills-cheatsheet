# Agent Skills Cheatsheet

> Version v0.3 · Data as of 2026-10-30 · Covers 22 entries with verifiable sources

A daily-updated, evidence-annotated guide to **agent skills** — the SKILL.md packages, plugin collections, frameworks, scanners and creation tools that extend coding agents such as Claude Code, Codex, Cursor, OpenCode and Gemini CLI.

Agent skills are becoming infrastructure: in October 2026 the GitHub trending charts were repeatedly topped by skill repos, and Anthropic donated the Agent Skills standard to the vendor-neutral Agentic AI Foundation. But the ecosystem moves fast and most lists go stale in a week. This one is maintained like a living document: every morning it is re-checked against the last 24 hours of releases, GitHub trending and community discussion — only what changed gets updated.

📖 **Read the full cheatsheet: [agent-skills-cheatsheet.en.md](agent-skills-cheatsheet.en.md)**

## How to use this cheatsheet

1. **Start with Quick picks by scenario** — the fastest path: name your job (audit agent-written code, de-slop AI design, do domain research, build your own skill…) and get a first choice plus backups.
2. **Drill into a category** — skills are classified by what they are *for*, not by who published them:
   - 🧑‍💻 Maintainer's own skills — Gamehu's own skills and skill tooling, kept in a separate category of their own
   - 🔐 Security & auditing — auditing agent-written code, scanning skills before install, benchmarked directories
   - 🎨 Design & UI — design vocabularies and anti-"AI-slop" skills for coding agents
   - 💻 Coding practice — engineering-style and methodology skills that change how an agent writes code
   - 🔬 Research & knowledge — domain skill packs (science, code knowledge graphs)
   - 🏛️ Official & platform collections — first-party skill/plugin catalogs from Anthropic, Google, Cursor, Salesforce…
   - 🧰 Harness & frameworks — skill frameworks and harness-tuning systems that organize many skills
   - 🛠️ Skill creation & tooling — tools that generate or capture new skills for you
3. **Check the entry fields** — every entry states, in plain language: what it does (the problem and the mechanism, in one sentence), what form it takes (single skill / collection / framework / scanner / creation tool), which agents it works with, its license, a dated star snapshot, and when it was first collected here.

## How to read the star counts

Star numbers are **dated snapshots** taken from the source that surfaced the project (usually GitHub trending coverage), not live counts — treat them as "heat at collection time", and open the repo for the current number. Entries whose description or license could not be verified from a primary source are marked **unverified** rather than smoothed over.

## Update cadence

Updated **daily** (morning, Asia/Shanghai). New skills are collected from GitHub trending, the agent ecosystem press, and community discussion; existing entries get refreshed snapshots when they move. The changelog at the bottom of the cheatsheet records every version. If a skill you care about is missing, open an issue — a source link is the fastest way to get listed.
